# Vibely LinkedIn Extractor - Landing Page

This folder contains the website for Vibely LinkedIn Extractor, used for Razorpay verification and extension promotion.

## Pages

- **index.html** - Landing page with features and pricing
- **privacy-policy.html** - Privacy Policy
- **terms.html** - Terms of Service
- **refund-policy.html** - Refund Policy
- **contact.html** - Contact page

## Deploy to GitHub Pages

1. Create a new GitHub repository (e.g. `vibely-extractor-site`)
2. Push this folder to the repository:
   ```bash
   cd extension-landing
   git init
   git add .
   git commit -m "Initial commit - landing pages"
   git remote add origin https://github.com/YOUR_USERNAME/vibely-extractor-site.git
   git push -u origin main
   ```
3. Enable GitHub Pages: Repo → **Settings** → **Pages** → Source: **main** branch → Save
4. Your site will be live at: `https://YOUR_USERNAME.github.io/vibely-extractor-site`

## Razorpay Verification

Add the GitHub Pages URL to Razorpay Dashboard → Account Settings for live mode verification.

## Update Contact Email

Edit `contact.html` and replace `support@vib3ly.shop` with your actual contact email if needed.
